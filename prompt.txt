* Graphic Design

Use only:

* HTML5
* CSS3
* Vanilla JavaScript

Do NOT use:

* React
* Angular
* Vue
* PHP
* Node.js
* Backend
* Database

* Desktop
* Laptop
* Tablet
* Mobile
